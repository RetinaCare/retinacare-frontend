# RetinaCare – Features

## 1. Homepage

- Hero section with clear messaging
- Mission and vision statements
- Service highlights
- Testimonials section
- Partner logos
- Responsive navigation and footer

## 2. Authentication (Login/signup)

- Email/password login
- Clean two-column layout (form + slideshow)
- Fully responsive

## 3. Predictor Dashboard

- Upload retinal image (.png, .jpg, .jpeg)
- Enter patient data:
  - HbA1c (%)
  - Duration of diabetes (years)
  - Systolic blood pressure (mmHg)
- Form validation using Zod + React Hook Form
- Sends data to `/predict` API endpoint
- Displays:
  - Risk severity
  - Confidence score
  - Recommendation message

## 4. Chat Assistant

- Offers real-time assistance to users
- Provides medical explanations and guidance
- development in view
