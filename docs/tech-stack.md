# RetinaCare – Technologies Used

## Frontend Framework

- React (Vite + TypeScript)

## UI & Styling

- TailwindCSS
- Custom components
- Responsive grid layouts
- Framer Motion for animation

## Form Handling

- React Hook Form
- Zod validation
- File upload handling

## API Handling

- Axios
- API abstraction layer in `/lib/config/api.ts`

## Icons

- Lucide-react

## Notifications

- React Toastify

## Routing

- React Router

## Deployment

- Vercel hosting for the live project

The project emphasizes performance, scalability, and clean component structure.
