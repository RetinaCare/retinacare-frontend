# RetinaCare – Project Overview

RetinaCare is a modern web application designed to help users assess their potential risk of Diabetic Retinopathy using patient data and retinal image uploads.

The platform provides:

- Authentication for users data security
- A clean user interface for entering patient information
- Retinal image upload
- AI-powered prediction results
- Confidence scores and medical recommendations
- A built-in chat assistant to guide users

This application focuses on simplicity, accessibility, and performance while offering helpful insights for diabetic patients and healthcare professionals.
